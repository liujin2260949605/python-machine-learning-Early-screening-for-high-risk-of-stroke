# python-machine-learning-Early-screening-for-high-risk-of-stroke
你是某医疗机构的数据分析师。公共卫生团队希望建立一个“卒中高风险早筛模型”，用于体检筛查、慢病管理和健康随访资源分配。这个模型不是用于临床确诊，而是用于提前发现高风险人群、降低高风险对象被漏掉的概率、辅助管理层安排筛查优先级与资源投入。管理层关心的是：哪些人更值得优先纳入筛查，模型是否能尽量减少高风险人群被漏掉，模型是否可解释并能指导资源分配。

项目目标
·理解卒中风险问题的业务定位。
·识别数据缺失、类别不平衡、弱解释变量等问题。
·完成探索分析与交叉分析。
·训练至少两种分类模型。
·合理比较 Recall、Precision、F1、ROC-AUC。
在本项目中，类别不平衡场景下必须设置召回率门槛：测试集 Recall 原则上不低于 0.60；达到 0.70 及以上可视为优秀。若未达到 0.60，必须说明原因，并展示至少一种改进尝试（如 class_weight、阈值调整、重采样等）。
·给出高风险人群画像。
·输出资源优先级建议与模型边界。

字段理解
字段	含义	教学提醒
id	样本编号	不参与建模
gender	性别	Other 样本极少，处理要说明
age	年龄	核心风险变量，应重点分析
hypertension	是否高血压	典型既往病史变量
heart_disease	是否心脏病	风险相关变量，适合交叉分析
ever_married	是否结婚	更像人口代理变量，不能过度因果解释
work_type	工作类型	可用于人群画像，但医学解释有限
Residence_type	居住类型	常作辅助探索变量
avg_glucose_level	平均血糖	重点变量，应重点可视化
bmi	体重指数	有缺失值，必须解释处理方式
smoking_status	吸烟状态	含 Unknown，不能简单忽略
stroke	是否卒中	正类极少，必须讲不平衡问题

任务流程

·识别字段类型。
·统计目标变量比例。
·检查缺失值与异常值风险。
·明确哪些字段不参与建模。

·处理 BMI 缺失值。
·处理 smoking_status 中的 Unknown。
·说明极少数类别值如何处理。
·说明为什么 id 不参与建模。
·不能只写“填补了缺失值”，必须说清为什么这样填，以及这样处理的风险是什么。

·至少覆盖：年龄与 stroke 的差异、平均血糖与 stroke 的差异、BMI 与 stroke 的差异、高血压与 stroke 的差异、心脏病与 stroke 的差异、吸烟状态与 stroke 的差异。

·必做交叉分析至少 2 组，建议优先从以下组合中选择：年龄 × 吸烟状态、年龄分层 × 高血压、年龄分层 × 心脏病、avg_glucose_level 分层 × BMI 分层、高血压 × 心脏病。
·也可以保留辅助型组合：heart_disease × work_type、hypertension × work_type。
·必须回答：哪类组合人群的卒中风险更高？这种交叉关系为什么比单变量更能支持筛查？如果资源有限，优先筛谁？

·至少训练两种模型，例如 Logistic Regression、Random Forest。
·要求输出 Accuracy、Recall、Precision、F1、ROC-AUC、混淆矩阵。
硬性要求：最终用于交付的模型 Recall 不得低于 0.60。若模型 Accuracy 较高但 Recall 偏低，仍不能判定为合格筛查模型。

·说明在卒中筛查场景中，为什么不能只看 Accuracy。
·说明为什么高 Recall 更重要。
必须结合业务代价解释：卒中筛查的首要目标是尽量少漏掉高风险人群，因此当 Recall 低于 0.60 时，应优先继续优化模型，而不是直接接受当前结果。
·如果一个模型 Accuracy 高但漏掉很多高风险人群，是否应选它。
·强调：这是风险筛查，不是比赛谁准确率更高。

·输出高风险画像。
·给出优先筛查人群建议。
·说明模型不能怎么用。
·说明结果解释边界。
